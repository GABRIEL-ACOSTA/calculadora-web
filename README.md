# Calculadora Web

## Descripción
Proyecto académico desarrollado con HTML, CSS y JavaScript.

## Funciones
- Suma, resta, multiplicación y división.
- Porcentaje y cambio de signo.
- Borrar el último carácter y reiniciar.
- Uso con botones o teclado.
- Interfaz adaptable a pantallas pequeñas.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
